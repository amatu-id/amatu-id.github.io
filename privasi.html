Kebijakan Privasi Portal AMATU

Berlaku untuk amatu-id.github.io dan semua aplikasi di dalamnya. Diperbarui 2 November 2026.

Data yang disimpan

  • Akun AMATU (nama pengguna, kata sandi dan PIN dalam bentuk hash) disimpan di server Portal AMATU (Supabase).
  • Data aplikasi Anda (dokumen, catatan, gambar, pengaturan) disinkronkan per akun agar sama di semua perangkat. Data kecil disimpan di Supabase, data yang lebih besar disimpan sebagai file di Google Drive milik pengelola Portal AMATU.

Google Drive

  • Portal AMATU memakai izin drive.file pada akun Google pengelola (amatusapa25@gmail.com): hanya file yang dibuat Portal AMATU sendiri di folder "AMATU Portal". File Drive lain tidak bisa dilihat.
  • Alamat email akun Google dibaca hanya untuk memastikan akun yang tersambung benar.
  • Token Google disimpan terenkripsi di server Portal AMATU dan hanya dipakai untuk menyimpan, membaca dan menghapus data sinkron. Data tidak dijual atau dibagikan ke pihak lain.
  • Akses dapat dicabut kapan saja di myaccount.google.com/permissions.
